# Car Price Predictor

A machine learning project that predicts car prices using linear regression.

## Overview

This project builds a predictive model to estimate car prices based on various features like engine size, horsepower, weight, and other specifications.

## Features

- Data loading and preprocessing
- Categorical variable encoding
- Linear regression model training
- Model evaluation with MAE, RMSE, and R² metrics
- Visualization of actual vs predicted prices
